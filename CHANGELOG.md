# Changelog

## v1.2.1 — 2026-09-28

- Исправлено копирование истории из каталога, в пути к которому есть пробелы.
- Аргументы Git и содержимое `commit.md` больше не проходят через shell; значения `--author` и пути не исполняются как команды.
- Повторный запуск с несколькими `--author` не дублирует уже скопированные коммиты.
- Удалены неиспользуемые и уязвимые runtime-зависимости. Добавлены проверка CLI и автоматический релиз с npm provenance.
