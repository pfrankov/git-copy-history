# Проверка поведения

- Действие: запустить `git-copy-history from "../source with spaces"` в пустом целевом репозитории. Результат: для каждого подходящего исходного коммита создаётся один коммит с хешем; пробелы в пути не мешают чтению истории.
- Действие: указать два разных `--author`, затем повторить ту же команду. Результат: выбираются коммиты обоих авторов, а повторный запуск не добавляет дубликатов.
- Действие: передать в `--author` кавычки и shell-метасимволы. Результат: значение используется только как фильтр Git и не исполняется как команда.
